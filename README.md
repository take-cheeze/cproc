# cproc (take-cheeze fork)

Fork of [cproc](https://codeberg.org/mcf/cproc), the C11 compiler front end that targets QBE
(upstream repository: https://codeberg.org/mcf/cproc).

- `master` and all other branches and tags are synced from Codeberg by `.github/workflows/sync.yml`
  (fast-forward only).
- `sync` holds only the sync workflow; don't build from it.

Used by [take-cheeze/nfcxx](https://github.com/take-cheeze/nfcxx) through `3rd/cproc`.
